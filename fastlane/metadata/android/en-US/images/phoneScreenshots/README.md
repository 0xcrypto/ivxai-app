Screenshots go here, as `1.png`, `2.png` and so on, in the order they should be
shown. F-Droid does not require them, but a listing without them is the one
nobody installs from.

Take them on a device or emulator with the release build installed:

    adb exec-out screencap -p > fastlane/metadata/android/en-US/images/phoneScreenshots/1.png

Delete this file once there are real ones beside it.
